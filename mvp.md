# Функциональные требования к MVP (WordTrainer)

## Основной Use Case: Изучение нового слова
**Актор:** Пользователь (студент, изучающий язык).
**Предусловия:** Пользователь открыл приложение, база слов содержит хотя бы одно слово.

**Основной сценарий:**
1. Пользователь переходит на страницу `/study` (Изучение).
2. Система отображает карточку `WordCard` с иностранным словом и контекстом его использования.
3. Пользователь нажимает на карточку (или кнопку), чтобы перевернуть её.
4. Система отображает обратную сторону карточки: перевод слова и перевод контекста.
5. Пользователь оценивает свое знание, нажимая кнопку «Выучил» или «Трудно».
6. Система сохраняет прогресс: обновляет уровень слова (`new`, `hard`, `learned`) и рассчитывает время следующего повторения (алгоритм интервальных повторений).
7. Система загружает следующую карточку из базы.

**Результат:** Прогресс пользователя обновлен (уровень слова изменен, дата повторения рассчитана), отображено новое слово.

**Альтернативный сценарий:** Слова в базе закончились. Система показывает сообщение «Вы повторили все слова!» и предлагает вернуться на главную страницу.

## Границы MVP
**Что войдет в MVP (реализуется в 6-й лабе):**
- Страница `/study` с работающей логикой переворота карточки.
- Оценка слова («Выучил»/«Трудно») и переход к следующему слову.
- **Ядро системы интервальных повторений**: изменение уровня слова и расчет времени следующего показа (система Лейтнера).
- Использование компонента `WordCard` из UI-библиотеки.
- Тестирование логики переворота и расчета интервалов (Jest).

**Что останется за пределами MVP (в будущем):**
- Реальная интеграция с Backend API или базой данных (в MVP данные хранятся локально в состоянии React/localStorage).
- Авторизация и личный кабинет пользователя.
- Продвинутая статистика и графики прогресса.
- Звуковое сопровождение и озвучка слов.
