# Архитектура проекта WordTrainer

## Структура проекта
Проект представляет собой монорепозиторий, состоящий из двух независимых пакетов:
1. **`app`** — основное приложение (React + Vite + TypeScript). Отвечает за отображение интерфейса, навигацию и взаимодействие с пользователем.
2. **`ui-library`** — библиотека общих переиспользуемых UI-компонентов (React + Vite + TypeScript). Обеспечивает единый стиль интерфейса.

### Структура пакета `app`
- `src/pages` — страницы приложения (HomePage, StudyPage, ProgressPage).
- `src/components` — специфичные для приложения компоненты (например, навигация).
- `src/router` — настройка маршрутизации с помощью `react-router-dom`.
- `src/assets` — статические ресурсы (картинки, стили).

### Структура пакета `ui-library`
- `src/components` — переиспользуемые UI-компоненты (Button, WordCard, ProgressBar).
- `src/index.ts` — точка входа для экспорта компонентов библиотеки.
- `src/setupTests.ts` — настройка тестовой среды.

## Используемые библиотеки
- **react** (v19.3.0) и **react-dom** (v19.3.0) — для создания пользовательского интерфейса.
- **react-router-dom** (v7.x) — для организации маршрутизации (SPA).
- **typescript** (v5.9.3) — для строгой типизации кода.
- **vite** (v8.x) — быстрый сборщик и dev-сервер.
- **jest** и **@testing-library/react** — для написания юнит-тестов.
- **eslint** — для проверки качества и стиля кода.

## Список разрабатываемых компонентов
### В библиотеке `ui-library`:
- `Button` — кнопка с вариантами стилизации (primary, secondary).
- `WordCard` — карточка для изучения слова (лицевая сторона с контекстом, обратная — с переводом).
- `ProgressBar` — визуальный индикатор прогресса изучения слов.

### В приложении `app`:
- `Navigation` — верхнее меню для переключения между страницами.
- `WordTable` — таблица со списком всех слов (для страницы прогресса).

## Структура роутинга
- `/` — Главная страница (приветствие, переход к обучению).
- `/study` — Страница изучения (отображение карточек слов).
- `/progress` — Страница прогресса (таблица слов и статистика).
- `/settings` — Защищенный маршрут (в будущем — настройки профиля).

## Использование библиотеки компонентов
Основное приложение `app` импортирует компоненты из `ui-library`. Например, на Главной странице используется компонент `Button` из библиотеки. В дальнейшем компонент `WordCard` будет использоваться на странице `/study`.
